# `orust-diag`

Diagnostics and generated-source reporting for ORust.

This crate connects ORust source spans with parser, emitter, Cargo, and Rust
compiler diagnostics. It supports stable ORust codes, JSON diagnostics, line
and column locations, and explanations suitable for CLI and editor clients.

See the [diagnostics guide](../../docs/diagnostics.md) and [error-code
registry](../../docs/error-codes.md).
